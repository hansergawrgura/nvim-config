# 快捷键

本 Neovim 配置的默认快捷键参考。

## 涵盖内容

- Leader 键与文件操作
- Buffer、窗口和标签页管理
- LSP 与诊断
- 通用与可视模式映射

## Leader 键

Leader 键为 **空格**（`<Space>`）。

## 通用

| 按键 | 模式 | 功能 |
|------|------|------|
| `<Esc>` | 普通 | 清除搜索高亮 |
| `<leader>w` | 普通 | 保存文件 |
| `<leader>wq` | 普通 | 保存并退出（Vim 传统写法） |
| `<leader>q` | 普通 | 退出窗口 |
| `<leader>x` | 普通 | 保存并退出 |
| `<leader>wa` | 普通 | 保存所有文件 |
| `<leader>nh` | 普通 | 清除搜索高亮 |
| `<leader>a` | 普通 | 全选当前文件 |
| `<leader>yf` | 普通 | 复制当前文件绝对路径 |

## Buffer 管理

| 按键 | 模式 | 功能 |
|------|------|------|
| `<leader>bb` | 普通 | 切换到上一个 buffer |
| `<leader>bd` | 普通 | 删除当前 buffer |
| `<leader>bn` | 普通 | 下一个 buffer |
| `<leader>bp` | 普通 | 上一个 buffer |

## 窗口导航

| 按键 | 模式 | 功能 |
|------|------|------|
| `<C-h>` | 普通 | 跳转到左侧窗口 |
| `<C-j>` | 普通 | 跳转到下方窗口 |
| `<C-k>` | 普通 | 跳转到上方窗口 |
| `<C-l>` | 普通 | 跳转到右侧窗口 |

## 窗口布局

| 按键 | 模式 | 功能 |
|------|------|------|
| `<leader>sv` | 普通 | 垂直分屏 |
| `<leader>sh` | 普通 | 水平分屏 |
| `<leader>se` | 普通 | 均衡窗口大小 |
| `<leader>sx` | 普通 | 关闭当前窗口 |

## 窗口调整

| 按键 | 模式 | 功能 |
|------|------|------|
| `<C-Up>` | 普通 | 增加窗口高度 |
| `<C-Down>` | 普通 | 减小窗口高度 |
| `<C-Left>` | 普通 | 减小窗口宽度 |
| `<C-Right>` | 普通 | 增加窗口宽度 |

## 标签页

| 按键 | 模式 | 功能 |
|------|------|------|
| `<leader>tn` | 普通 | 新建标签页 |
| `<leader>tc` | 普通 | 关闭标签页 |
| `<leader>to` | 普通 | 只保留当前标签页 |
| `<leader>tl` | 普通 | 下一个标签页 |
| `<leader>th` | 普通 | 上一个标签页 |

## LSP 与诊断

| 按键 | 模式 | 功能 |
|------|------|------|
| `[d` / `]d` | 普通 | 上一个 / 下一个诊断 |
| `<leader>de` | 普通 | 显示当前诊断 |
| `<leader>dl` | 普通 | 将诊断放入 location list |
| `<leader>lh` | 普通 | 显示 LSP hover 文档 |
| `<leader>ld` / `<leader>lD` | 普通 | 跳转到定义 / 声明 |
| `<leader>li` / `<leader>lt` | 普通 | 跳转到实现 / 类型定义 |
| `<leader>lr` | 普通 | 列出引用 |
| `<leader>rn` | 普通 | 重命名符号 |
| `<leader>ca` | 普通 | 执行代码操作 |
| `<leader>lf` | 普通 | 使用 LSP 格式化 |

## 工具与维护

| 按键 | 模式 | 功能 |
|------|------|------|
| `<leader>tt` | 普通 | 打开终端 |
| `<leader>lm` | 普通 | 打开 Mason |
| `<leader>ll` | 普通 | 打开 Lazy |

## 可视模式

| 按键 | 模式 | 功能 |
|------|------|------|
| `J` | 可视 | 将选中行下移 |
| `K` | 可视 | 将选中行上移 |

## 自定义

快捷键定义在 `lua/config/keymaps.lua`。
使用 `vim.keymap.set` 添加或修改映射：

```lua
vim.keymap.set("n", "<leader>w", "<cmd>write<CR>", { desc = "保存文件" })
```
