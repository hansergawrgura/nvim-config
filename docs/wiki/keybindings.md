# 快捷键

本 Neovim 配置的默认快捷键参考。

## 涵盖内容

- Leader 键
- 通用映射
- 窗口导航与调整
- 可视模式映射

## Leader 键

Leader 键为 **空格**（`<Space>`）。

## 通用

| 按键 | 模式 | 功能 |
|------|------|------|
| `<Esc>` | 普通 | 清除搜索高亮 |
| `<leader>w` | 普通 | 保存文件 |
| `<leader>q` | 普通 | 退出窗口 |
| `<leader>x` | 普通 | 保存并退出 |

## 窗口导航

| 按键 | 模式 | 功能 |
|------|------|------|
| `<C-h>` | 普通 | 跳转到左侧窗口 |
| `<C-j>` | 普通 | 跳转到下方窗口 |
| `<C-k>` | 普通 | 跳转到上方窗口 |
| `<C-l>` | 普通 | 跳转到右侧窗口 |

## 窗口调整

| 按键 | 模式 | 功能 |
|------|------|------|
| `<C-Up>` | 普通 | 增加窗口高度 |
| `<C-Down>` | 普通 | 减小窗口高度 |
| `<C-Left>` | 普通 | 减小窗口宽度 |
| `<C-Right>` | 普通 | 增加窗口宽度 |

## 可视模式

| 按键 | 模式 | 功能 |
|------|------|------|
| `J` | 可视 | 将选中行下移 |
| `K` | 可视 | 将选中行上移 |

## 自定义

快捷键定义在 `lua/config/keymaps.lua`。
使用 `vim.keymap.set` 添加或修改映射：

```lua
vim.keymap.set("n", "<leader>w", "<cmd>write<CR>", { desc = "保存文件" })
```
