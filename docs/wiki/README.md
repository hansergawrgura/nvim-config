## 新增指南

当你添加了面向用户的功能并完成测试后，在 `docs/wiki/<主题>.md` 创建新指南：

1. 清晰的标题 + 一句话描述
2. "涵盖内容" 小节列出范围
3. 相关代码示例（代码保持英文）
4. "相关指南" 小节链接到相关条目
5. 在上方表格中添加条目
